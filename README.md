# SpamShield: NLP Spam vs Ham Classifier

Spam detection using TF-IDF and Logistic Regression, with a FastAPI backend and a custom frontend.

**Pipeline:** tokenization, stopword removal, stemming, TF-IDF, classification, evaluation.

**Dataset:** SMS Spam Collection (about 5,500 messages).
